# Metric Time

A modern, decimal-based timekeeping system designed for global coordination and digital simplicity.

## 🌍 About Metric Time

Metric Time divides the 24-hour day into decimal units for intuitive, consistent timekeeping:

- **1 Day** = 10 mHours
- **1 mHour** = 100 mMinutes = 2 hours 24 minutes
- **1 mMinute** = 100 mSeconds = 1 minute 26.4 seconds
- **1 mSecond** = 0.864 traditional seconds

## 📅 Metric Calendar

The Metric Calendar organizes the year into 10 months of 36-37 days each, with a consistent work-rest rhythm:

- **10 Months:** Renewal, Awaken, Bloom, Thrive, Radiate, Sustain, Gather, Reflect, Diminish, Restore
- **6-Day Weeks:** 2 rest days + 4 work days
- **Predictable Rhythm:** Same pattern every month for better planning and coordination

## ✨ Website Features

- **Live Metric Time Display** — Real-time clock showing current time in both metric and traditional formats
- **Interactive Time Converter** — Bidirectional converter between traditional and metric time
- **Year-View Metric Calendar** — Visual grid showing all 10 months with color-coded work/rest days
- **Educational Content** — Comprehensive guide to metric time benefits and applications
- **Modern Design** — Clean, minimalist aesthetic with teal accents and geometric layout

## 🚀 Deployment

This website is deployed via GitHub Pages and is live at [metrictime.info](https://metrictime.info)

### To Deploy Locally

1. Clone this repository
2. Open `index.html` in your web browser
3. No build process or dependencies required

### To Deploy to GitHub Pages

1. Go to your repository Settings → Pages
2. Select the branch containing `index.html`
3. Add your custom domain in the Pages settings
4. Update DNS records at your domain registrar
5. Your site will be live at your custom domain

## 🎯 Why Metric Time?

**For Individuals:** Clear work-rest rhythm, intuitive planning, easier vacation cycles

**For Technology:** Better suited to digital systems, eliminates uneven month lengths, universally applicable

**For Society:** Cross-cultural coordination, fixed seasonal anchors, global project timelines
